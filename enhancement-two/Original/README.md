# CS-300-Data-Structures-and-Algorithms

# 1.) What was the problem you were solving in the projects for this course?
-In Project One, I had to create pseudocode for three data structures: vector, hash table, and tree. I also had to create pseudocode for a menu and also to print out the list of the courses in the Computer Science program in alphanumeric order. Then I had to evaluate the run time and memory of data structures that could be used to address the requirements. The reason for this is because I had to determine which data structure I had planned to use in my code moving forward. This was based on the advantages and disadvantages of each structure in my evaluation based on the Big O analysis results and my own analysis of the three data structures. So, I had to apply non-coding development methodologies for outlining an algorithmic design and evaluate complex data structures that solved a given problem using advanced algorithmic designs to develop advising assitance software.

-In Project Two, I had to develop code using algorithms and data structures to solve basic programming problems with all of the necessary functions working and correctly without using CSVParser or other header files based off of my recommendation from Project One for a data structure. I had to write the code for the application based off of a hash table pseudocode so the department advisors can use it to help them when they talk with students for advising assistance.  

# 2.) How did you approach the problem? Consider why data structures are important to understand.
-I approached the problem by conducting a thorough analysis of multiple data structures to evaluate their performance regarding memory usage and runtime efficiency. Understanding data structures is crucial because it impacts the effectiveness of algorithms, particularly when it comes to searching, inserting, or sorting data. This foundational knowledge allowed me to make informed decisions about which data structure would best to meet the needs of the course management system.

# 3.) How did you overcome any roadblocks you encountered while going through the activities or project?
-I faced a challenge in Project One when I was trying to determine the best data structure moving forward for Project Two. After evaluating the run time and memory of data structures, I was able to see that the hash table was the best choice to go with. My choice was based on performance, implementation simplicity, ordered access not being essential, and space utilization. With an average-case time complexity of O(1) for insertions and lookups, the hash table's efficiency substantially enhances the course management system's performance regarding quick access to course details and associated prerequisites. The optimal scenario for constant-time complexity is highly beneficial when dealing with potentially large datasets, such as numerous courses with various prerequisites.
